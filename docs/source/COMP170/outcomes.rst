*******************************************************************************
Course description and outcomes
*******************************************************************************

COMP 170 introduces programming from first principles along three parallel tracks: Python programming concepts (following *Think Python*), Unix command-line tools (following *The Linux Command Line*), and the mathematical foundations underneath them — logic, sets, functions, and introductory algorithm analysis. By the end of the course, students write multi-class Python programs with docstrings and assertion-based tests, navigate the command line fluently, and connect programming constructs to the discrete-math ideas behind them.

**Problem Decomposition and Algorithm Design:** Ability to take a problem, break it into parts, specify algorithms, and express a solution in terms of variables, data types, input/output, repetition, choice, arrays, subprograms, classes, and objects.

**Program Evaluation:** Ability to judge a good program.
